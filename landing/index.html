W-01 // THE PROBLEM

          
One wrong
step.

          
The first astronauts on Mars will walk terrain no human has ever seen —
          where a slope past 30°, a boulder field, or a dust front can end a mission.
          NASA has mapped all of it for fifty years. But the knowledge lives in
          seven separate archives built for scientists, not for the
          person inside the suit.

W-02 // THE CONCEPT

        
One map.
Three states of a
Marswalk.

      

      

        

          
          
          
        

        

          

            

              
Mission planning, hours before the airlock

              
Toggle the layers. Drop a landing point, mark the science stations,
              and RedSight computes the full traverse — avoiding crater walls, boulder
              fields and radiation exposure — with an EVA report for every step:
              distance, energy, dose, consumables.

              
    
                
  • COST MODEL — JPL MARS 2020 TRAVERSABILITY (ONO 2016)
    • 
                
  • CONSTRAINTS — SLOPE 30° · ROCK CFA 15%
    • 
                
  • OUTPUT — EVA REPORT + ROUTE PROFILE
    • 
              

            

            

              
            

          

          

            

              
The walk itself, inside the helmet

              
The same route, rendered as a heads-up display on the visor: waypoint
              cues, live telemetry, and point-of-view imagery from NASA rovers at each
              stop — so the crew knows exactly what the terrain looks like before
              they arrive. The challenge brief itself invites this format. We ship it.

              
    
                
  • WAYPOINT CUES + BEARING TICKS
    • 
                
  • POV IMAGERY — ROVER NAVCAM / MASTCAM
    • 
                
  • HAZARD CALLOUTS AT 20 M RESOLUTION
    • 
              

            

            

              
            

          

          

            

              
When Mars changes its mind

              
A dust front rolls over the planned traverse. RedSight doesn't freeze —
              it replans in seconds using D* Lite incremental search, diverging the crew
              around the new hazard while the EVA report updates live. Alive, not static.

              
    
                
  • D* LITE INCREMENTAL REPLAN

W-03 // THE SCIENCE

        
Every pixel
has a citation.

        
RedSight's route engine is a faithful simplification of the traversability
        analysis JPL used to select Perseverance's landing site. No invented numbers.
        Every constant on screen carries its source.

      

      

        

          
COST MODEL — PER TRAVERSE STEP

          
blocked if slope ≥ 30° or rock CFA > 15%

cost(step) = d × [ wE·Ê(θ) + wT·(1/v(θ)) + wR·H(cell) ]

  Ê(θ) = m·g·(sinθ + Crr·cosθ) / E_ref
  v    = speed(θ, terrain class)
  H    = a·rock + b·dust τ + c·radiation

          
USER DIALS: wE ENERGY · wT TIME · wR RISK — PRESETS: FASTEST / SAFEST / GREENEST
